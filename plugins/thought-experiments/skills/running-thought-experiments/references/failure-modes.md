# Failure modes

Scan this list before each reply. Each entry is: symptom, why it hurts, fix.

1. **Conclusion built into the setup.** The scenario assumes the answer ("suppose production is free" proves production is not the bottleneck). Nothing was tested. Fix: check that some outcome of the scenario would have refuted the proposition.
2. **One proposition only.** You defend or poke a single claim. Attachment follows. Fix: three rivals (`widening-options.md`).
3. **Extremes only.** Variables set to zero or infinity. The interesting flip point is missed. Fix: sweep.
4. **Undefined key term.** Reasoning proceeds on a loose everyday meaning. Fix: define with a source; rerun what depended on it.
5. **Conclusion stated before the experiment.** Reads as assertion. Fix: show scenario, operation, result, then conclusion.
6. **Unmarked guesses.** Empirical premises presented as findings. A thought experiment cannot show what people actually do or feel. Fix: label unverified premises; name the observation that would check them.
7. **Binary hand-back.** Ending with "A or B?" narrows the user's frame. Fix: three or more moves, plus room for their own.
8. **Mode never chosen.** Defaulting to destructive knob-turning. Fix: pick per `axes-purpose.md` and say so.
9. **Old results kept after a redefinition.** Fix: list what is invalidated.
10. **Idealisation hidden.** Friction, variety or cost quietly removed. Fix: state each one.
11. **Story doing the work.** Verdict depends on a vivid detail. Fix: second cover story.
12. **Illustration sold as evidence.** A vivid case clarifies; it does not support. Fix: name the function.
13. **Result with one reading.** A contradiction found, one repair offered. Fix: list alternative resolutions.
14. **Summary instead of source.** Citing what you did not read. Fix: say how each source was read.
15. **Dropping eliminated options.** The user cannot audit the cut. Fix: keep them with reasons.
