# Axes: procedure

## 7. Skeleton
- **Four steps**: proposition, scenario, operation, conclusion. Good default.
- **Six steps**: question, scenario, unfold, output, expose an inconsistency, resolve it. Use when the aim is to find what conflicts. Treat the resolution as a conjecture; several usually exist.
- **Core and extended**: core = scenario + question + verdict. Extended = an argument from the verdict to a target claim. One core can feed several arguments; several cores can feed one.

## 8. Manipulations
- **Gradual sweep**: move one variable step by step; locate the flip point.
- **Turn every knob**: change each detail of the scenario; see which ones the verdict depends on.
- **Matched pair**: two cases differing in one factor.
- **Controls**: add a case where the answer is plainly yes and one where it is plainly no.
- **Factor isolation**: build a family of variants; check whether the verdict moves with the factor.
- **Rival theories on one case**: find where they disagree.
- **Extreme case**: exaggerate to make a weak expectation visible.
- **Limit**: push a familiar case to its limit.
- **Idealise**: drop irrelevant properties, then frictions. Say which; a critic may refuse them.
- **Cover stories**: same structure, different narratives, to check the story is not doing the work.

## 9. Medium of reasoning
- Explicit argument: list premises, derive.
- Mental model: build a representative situation and run it.
- Imagery: spatial reasoning, symmetry, combining motions.
- Immediate judgment about the case. Weakest alone; pair with another.

## 12. Whose judgment
- Yours alone.
- You and the user: works only on shared beliefs and a shared order of which belief to give up first.
- Many people: verdicts vary by background; suggest asking others when it matters.

## 13. Relation to real tests
- Stays in thought.
- Precursor: ends by naming the real observation that would settle it.
- Evaluative: designed to test a model, versus merely predicting an untried case.
