# Value checks

A run can satisfy every stage and still say only what the field already knows. Run these checks so the effort goes where an answer is not yet known.

## Stage A, before the rivals
1. **Prior answer.** Search for the favourite proposition and its opposite in papers, official reports and the minutes of bodies that decide the matter. If either is already argued with evidence, say so and cite it, then propose a sharper question that starts where that work stops. Rebuilding a known answer spends the whole run on nothing new.
2. **A real holder.** In destructive mode, show that someone actually holds or acts on the proposition you will attack: a document, a decision record, a stated rule. No holder found? Say it is a strawman and attack the strongest position that is held. Refuting a view nobody takes changes no one's mind.
3. **Prediction.** Write down what an informed practitioner would expect the result to be, and how sure they would be. Keep it in the state. A result is valuable to the degree it departs from this.

## Stage C, before the conclusion
4. **Compare with the prediction.** Say plainly whether the result matched it. If it matched, label the conclusion "confirms existing view" and say what, if anything, is new: a number, a mechanism, a boundary, a reproducible check. The user decides whether that is worth keeping; do not dress a confirmation as a finding.
5. **Who would change their mind.** Name the reader and the decision. If you cannot name one, say the run has no audience yet.

## When the user says it is obvious
Do not defend the result. Check which of 1 to 5 was skipped, say so, and offer a question that passes them.
