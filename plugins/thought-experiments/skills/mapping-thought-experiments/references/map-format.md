# 地図の書式と、候補の出し方

雛形は `assets/map.toml`。`map.html` は `thought_map.py render` が生成するので、直接編集しない。`check` は、形式と、`map.html` が `map.toml` から生成した最新のものかを検査する（CI や pre-commit に入れられる）。

## 軸

`[rows]` と `[cols]` の2つだけ。3つ目の観点が要るときは、別の地図に分ける（表が読めなくなるため）。

| 欄 | 意味 |
| --- | --- |
| `basis` | `standard`（規格・仕様）、`paper`（論文・サーベイ）、`own`（自作） |
| `ref` / `ref_title` | 出典。URL か、`--root` からの相対パス |
| `ref_read` | 出典の本文で、値の定義を確かめたか |
| `values` | `id`（セルの指定に使う。変えない）、`name`、`note`（値の定義） |

## セルの状態

書いていないセルは `unexplored`。「埋まった」と数えるのは `supported` と `refuted` だけ（否定も結論）。

| status | 記号 | 意味 |
| --- | --- | --- |
| `open` | ? | 問いだけがある（`next_question` に問いを書く） |
| `hypothesis` | △ | 仮説はあるが裏付けがない |
| `supported` | ◎ | 根拠のある結論 |
| `refuted` | ✕ | 仮説が否定された |
| `contested` | ! | 根拠が衝突している |
| `out_of_scope` | — | 扱わない（理由を `claim` に書く） |

## 候補の順位

点数の高い順。理由（`why`）と、推論の前提にするセル（`premises`）が付く。

| 点 | 対象 | 推論の方向 |
| --- | --- | --- |
| 100 | `contested` | どの前提が違うかを特定する（崩す） |
| 80 | `hypothesis` | 反例を探す。なければ根拠を足す（崩す） |
| 75 | 自作の軸 | 既存の分類と突き合わせ、欠けている値を探す（広げる） |
| 70 | `open` | 置かれた問いに答える（組み立てる） |
| 65 | 根拠のない結論 | 根拠を足すか、仮説に戻す |
| 50 | 出典を未確認の軸 | 本文で値の定義を確かめる |
| 40〜80 | 空のセル | 同じ行・列の結論の数で加点。両方にあれば2つを前提に組み立てる。片方なら、その結論が移るかを試す。どちらもなければ、問いを立てて広げる |

点数は、どこから考えるかの目安で、正しさの尺度ではない。利用者が別の順を選んだら従う。
