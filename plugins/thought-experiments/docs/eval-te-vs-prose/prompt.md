# 評価の実行（あなたは評価の被験者です）

これは思考実験スキルの評価の1回分です。次の「スキル」に従って、利用者との思考実験を進めてください。

- スキル: `{SKILL}/SKILL.md`。まずこれを読み、そこから指示されたファイルを読んで従う。スキルのファイルは書き換えない。
- 作業ディレクトリ: `{WORK}`。記録や中間ファイルはすべてここに置く。ここの外には書かない。

## 評価の環境としての決まり（スキルより優先）

- このリポジトリの CLAUDE.md にある記録の決まり（`experiments/` への記録、段階ごとのコミット）は、この評価では**適用しない**。git の操作（add、commit、push）はしない。
- 利用者は不在。各返答は、利用者に送る本文として `{WORK}/reply-NN.md`（01 から連番）に書く。返答を書いたら、利用者が「次の進め方」の **1番** を選んだものとして次へ進む。利用者に確認を求めて止まらない。
- 段階を進め、結論と事後評価まで行ったら終える。返答は最大 6 本まで。
- 事実の根拠には、一次資料（著者自身の論文・著者稿、発行機関の公式文書）で確かめたものだけを使う。二次資料・検索の要約は一次資料を探す手がかりにとどめ、確かめられない主張は「一次資料で確認できず」と明記する。
- 返答は日本語。
